n8n cannot be leveraged for building Agent orchestration. it can only simulate sequential, parallel (fan-out + Merge node) and loop (Split in Batches + cycle back) patterns between agents using generic workflow graph mechanics - none of it agent-aware (no shared session state, no iteration guards, no dynamic composition) 
- Missing A2A support - n8n support communication between 2 agent nodes by passing the state as a JSON over HTTP as it would have passed it while invoking any tool. the A2A protocol is not at all supported, which means following are not available
	-  Agent Cards (/.well-known/agent-card.json) describing agents capability and discoverability is missing. Without this, dynamic agent discovery isn't possible - orchestration requires hardcoding each agent's endpoint and capabilities upfront.
	- A standardized, stateful task lifecycle i.e. submitted -> working -> input-required -> completed/failed/canceled. This is needed for hooks and HITL - partially implemented via wait node (similar to task sent for human review), but only between workflow nodes, not inside an agent's own reasoning loop
	- Streaming/resubscribe n8n executions are start-to-finish there's no standardized reattach
	- Cross-framework interoperability - the actual point of the protocol: Agent A (Strands) and Agent B ( LangGraph, ADK, Glean) can talk without either knowing the other's internals, because both speak A2A. n8n isn't itself an A2A-compliant agent (no agent card, no task endpoints) This needs to be built as a wrapper.  Today n8n can call out to an A2A agent as a dumb HTTP client, but it can't participate as a peer.
- No shared-state concept for an orchestrator role. n8n do not have any shared state concept which makes it difficult to implement a node which can act like an Orchestrator . All agents are working independently and in silos. This needs to be handled through designing
- HITL via wait node. HITL between 2 nodes is possible by introducing “Human Review”. However HITL inside the AI Agent node's own reasoning loop (thought → call tool → observe → repeat) is not supported 
- Gaurdrails - n8n can only gaurd at the edge while in the agents its needed inside node between every tool call
